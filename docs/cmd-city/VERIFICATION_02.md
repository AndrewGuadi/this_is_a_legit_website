## Measured performance

The final manager run of the existing 1,280-tile stress fixture measured median 5.55 ms, p95 19.75 ms, maximum 39.25 ms over 120 months. Its initial 43,200 population declined to 0; it is explicitly **not sustained populated-city evidence**. Earlier uncorrected integration measured approximately66.81 ms p95. CPU profiling found lost road-order cache identity and repeated employment routing; bounded derived caches and fresh returned arrays corrected that regression.

The new reproducible `node tests/city/sustained-benchmark.mjs` fixture independently addresses that limitation. The manager's run held **4,800 residents for every one of 120 months**, with 2,800 workers, 2,880 job positions and 2,136 employed. All four utility ratios remained 1, health remained 96.34, and finite groundwater fell 1,000,000→59,800. Initial/final saves validated. No model overrides or mid-run resource/population replenishment occurred. Its timing was median 6.09 ms, p95 8.75 ms, maximum 24.37 ms. Synthetic starting capital, buildings and stock are disclosed; the remaining real road bottleneck is reported rather than hidden.

Both measurements used Node 24.19.0/Linux x64 on AMD EPYC 9V74. They measure CPU model advancement, not renderer/frame timing, physical-device behavior, every possible city layout, or full feature equivalence.
