## Findings and gates

### 1. Worker-controlled evidence integrity — blocker
run_task.py collects git diff against a worker-writable index and metadata. Staging modifications can hide changes from the proposed patch. Worker-written logs are not authoritative test evidence.
Required: export the candidate and compare it outside the worker against a manager-owned immutable snapshot; reject unexpected paths, modes and symlinks; generate the authoritative patch externally. Independently rerun tests.

### 2. Isolation and output bounds — blocker
The python* command allowance permits arbitrary Python execution and network calls. Network restrictions are prompt instructions rather than enforced controls; the output volume lacks the tmpfs size bounds.
Required: enforced egress restrictions and private-network isolation, bounded output, and executed Docker tests for permissions, timeout, cleanup and artifact extraction. Non-root execution, dropped capabilities and no host source mounts are useful existing controls.

### 3. Research validity — high
Visible research disclosure and synthetic-only forms affect the sample. There is no permission registry or independent agent identity. Signed tokens establish possession, not comprehension or legal authority. No exposure denominator supports a compliance-rate claim.
Required: define research question and metric, distinguish authorization states and unknown actors, use known permitted/unpermitted test agents in a controlled benchmark, and avoid assertions about identity or intent beyond available evidence.

### 4. Operations — high
Count-then-write throttling races under concurrency; rate-limited attempts are not recorded; inactivity retention depends on external scheduling; proxies may group unrelated visitors.
Required: production proxy checks, concurrent limit tests, bounded storage, scheduled expiry and backup handling, authorization tests and export-completeness verification.

### 5. UI and investigator usefulness — pending
Current visual direction is coherent by source inspection, but unrendered. Investigation is a JSON export limited to 1,000 records.
Required: review at 360/390/768/1440 widths, keyboard and screen-reader flows, AA contrast, reduced motion, no overflow/layout shifts, recoverable validation and an authenticated investigation UI. Define named comparators and a rubric before claiming visual superiority.
